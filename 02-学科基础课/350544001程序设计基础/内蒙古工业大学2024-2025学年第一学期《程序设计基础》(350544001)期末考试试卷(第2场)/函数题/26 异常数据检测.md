## 题目描述

在数据分析领域，异常检测是一项至关重要的任务。异常数据通常是指与正常数据模式不符的数据点，它们可能是由于系统故障、恶意攻击或其他原因产生的。通过检测异常数据，我们可以及时发现潜在的问题，从而采取相应的措施来解决问题，提高系统的稳定性和安全性。

比如在传感器网络中（如压力传感器），需要实时监测数据的异常情况。如果传感器的两次读数异常接近最低值，那么第二低的值可能同样具有重要意义。现在请你在传感器采集到的若干个数据当中，找出第二低的值，也就是仅高于最低值的次低值。

---

## 函数接口定义

```c
int secondLow(int values[], int size);
```

其中 `values[]` 和 `size` 都是用户传入的参数。`values[]` 存放的是传感器采集到的数据集合，其值是不超过 100 的正整数；`size` 是集合中数据的个数。函数须返回 `values[]` 中的第二低值（仅高于最低值的值）。如果没有第二低值，则返回 -1。

## 裁判测试程序样例

```c
#include <stdio.h>
int secondLow(int values[], int size);

int main() {
    int N, i, second, val[100];
    scanf("%d", &N);
    for (i = 0; i < N; i++) {
        scanf("%d", &val[i]);
    }
    second = secondLow(val, N);
    printf("%d", second);
    return 0;
}
```
