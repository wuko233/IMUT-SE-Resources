# 22 奇平方和

**分数**：20  
**作者**：anshiny  
**单位**：内蒙古工业大学

---

## 题目描述

玛丽同学正在学习数列的相关知识，她遇到了一个有趣的数列问题。这个数列被称为"奇平方和数列"，定义如下：

从 1 到 N 之间的所有奇数的平方和。

例如，如果 N = 5，那么需要计算 1² + 3² + 5² = 1 + 9 + 25 = 35。

请你编写一个 C 语言程序，从用户那里接收一个正整数 N（1 <= N <= 100），并计算从 1 到 N 的所有奇数的平方和，然后输出结果。

---

## 输入格式

输入一个小于 100 的正整数 N。

---

## 输出格式

输出 1 到 N 之间所有奇数的平方和。

---

## 输入样例

```
5
```

## 输出样例

```
1到5之间所有奇数的平方和为35。
```
