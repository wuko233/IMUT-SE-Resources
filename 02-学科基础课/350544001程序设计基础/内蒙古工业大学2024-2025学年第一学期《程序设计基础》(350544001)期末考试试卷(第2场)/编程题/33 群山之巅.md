# 33 群山之巅：寻找最高峰之后的风景

**分数**：20  
**作者**：imut007  
**单位**：内蒙古工业大学

---

## 题目描述

数据学院创新创业社团进行的一次科考探险活动中，同学们测量了多个山峰的高度，每个山峰的高度是唯一的。为了更好地分析这些数据，我们需要找到最高峰（数据中的最大值），并输出这个最高峰之后的所有数据。这些数据可以帮助我们了解在到达最高峰之后山峰高度的变化情况。

---

## 输入格式

在一行中给出正整数 N（2 ≤ N ≤ 50）表示测量的山峰数量。随后一行，给出 N 个不同的整数，代表采集到的山峰高度，中间以空格分隔。

---

## 输出格式

输出最高峰之后的数据，中间以空格分隔；如果不存在则输出 `None`。

---

## 输入样例 1

```
5
6962 8848 7782 8167 7538
```

## 输出样例 1

```
7782 8167 7538 
```

## 输入样例 2

```
2
6962 8848
```

## 输出样例 2

```
None
```
