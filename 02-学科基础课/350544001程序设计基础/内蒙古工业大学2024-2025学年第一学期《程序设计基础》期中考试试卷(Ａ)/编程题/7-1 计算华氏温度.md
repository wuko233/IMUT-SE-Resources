# 7-1 计算华氏温度

**分数**：25  
**作者**：anshiny  
**单位**：内蒙古工业大学

---

## 题目描述

华氏温度（F）与摄氏温度（C）是两大国际主流的计量温度的标准。华氏温标是德国人华伦海特(Fahrenheit)创立的温标，他以水银作测温物质，定冰的熔点为32度，沸点为212度；摄氏温标是瑞典人安德斯·摄尔修斯(Celsius)提出在标准大气压下，把冰水混合物的温度定为0摄氏度，水的沸点规定为100度。

本题要求编写程序计算摄氏温度对应的华氏温度，计算公式为：

> F = 9 × C / 5 + 32

式中：C 表示摄氏温度，F 表示华氏温度，输出数据要求为实型。

---

## 输入格式

输入一个代表摄氏度的整数。

---

## 输出格式

按照下列格式输出：

```
C=输入的整数,F=对应的华氏温度实数值
```

其中 F 的值保留一位小数。

---

## 输入样例

```
34
```

## 输出样例

```
C=34,F=93.2
```

> 提示：输出实型数据时可用 `%.1lf` 格式来控制只输出 1 位小数。
