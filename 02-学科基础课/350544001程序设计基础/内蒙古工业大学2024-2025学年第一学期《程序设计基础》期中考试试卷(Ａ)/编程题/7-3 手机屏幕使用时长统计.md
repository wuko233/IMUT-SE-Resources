# 7-3 手机屏幕使用时长统计

**分数**：25  
**作者**：Xinghm  
**单位**：内蒙古工业大学

---

## 题目描述

设计一个程序，用于统计和分析用户手机屏幕的使用时长。程序需要读取用户在一周（7 天）内每天的手机屏幕使用时长（以分钟为单位），然后计算并输出用户在一周内平均每天使用手机屏幕的时长。

如果输入的值小于 0 或者大于 1440，则输出 `Invalid Value`。

---

## 输入格式

输入 7 个整数代表一个用户 7 天的手机屏幕使用时长。

---

## 输出格式

一个浮点数，代表每天的手机屏幕平均使用时长，结果保留 1 位小数。

---

## 输入样例 1

```
320 200 400 150 180 230 100
```

## 输出样例 1

```
225.7
```

## 输入样例 2

```
120 -30 300 250 280 430 20
```

## 输出样例 2

```
Invalid Value
```
