## 0. 先看考试题型

练习题1围绕图书管理系统，有 4 张表：

| 表名 | 含义 | 主要字段 |
|---|---|---|
| `dzb` | 读者表 | `dzid` 读者ID，`xm` 姓名，`dh` 电话，`zcrq` 注册日期 |
| `tsb` | 图书表 | `tsid` 图书ID，`sm` 书名，`zz` 作者，`cbz` 出版社，`cbrq` 出版日期，`jg` 价格，`tslbid` 图书类别ID |
| `jyb` | 借阅表 | `jlid` 记录ID，`dzid` 读者ID，`tsid` 图书ID，`jyrq` 借阅日期，`ghrq` 归还日期，`jyzt` 借阅状态 |
| `tslbb` | 图书类别表 | `lbid` 类别ID，`lbm` 类别名 |

常考内容：

1. 关系代数：选择、投影、连接。
2. SQL：建表、插入、更新、删除、查询统计、视图、索引、变量。
3. 存储过程、触发器、授权。
4. 范式、闭包、候选码。
5. E-R 图转关系模式。
6. 事务：`BEGIN TRANSACTION`、`COMMIT`、`ROLLBACK`。

## 1. 数据库最基础概念

### 1.1 表、字段、记录

数据库里的数据通常放在“表”里：

- 表：比如 `读者表 dzb`。
- 字段：表的列，比如 `dzid`、`xm`、`dh`。
- 记录：表的一行，比如一个读者的信息。

### 1.2 主键、外键

主键是“唯一标识一行”的字段。

例如：

```sql
dzb(dzid, xm, dh, zcrq)
```

这里 `dzid` 可以作为主键，因为每个读者的 ID 不应重复。

外键是“引用别的表主键”的字段。

例如：

```sql
jyb(dzid) REFERENCES dzb(dzid)
jyb(tsid) REFERENCES tsb(tsid)
```

意思是：借阅表里的读者必须是真实存在于读者表里的读者，借阅表里的图书必须是真实存在于图书表里的图书。

### 1.3 常见 SQL 分类

| 类型 | 作用 | 例子 |
|---|---|---|
| DDL | 定义数据库对象 | `CREATE TABLE`、`CREATE VIEW`、`CREATE INDEX` |
| DML | 操作数据 | `INSERT`、`UPDATE`、`DELETE` |
| DQL | 查询数据 | `SELECT` |
| DCL | 权限控制 | `GRANT` |
| TCL | 事务控制 | `BEGIN`、`COMMIT`、`ROLLBACK` |

## 2. 关系代数速成

关系代数题一般只考 3 个符号：

| 符号 | 名字 | SQL 类比 |
|---|---|---|
| `σ` | 选择 | `WHERE` |
| `π` | 投影 | `SELECT 字段` |
| `⋈` | 连接 | `JOIN` |

### 2.1 解题套路

1. 先看题目要什么字段，最后用 `π` 投影。
2. 再看条件，条件用 `σ` 选择。
3. 如果条件或结果来自多张表，要先连接。

### 2.2 操作题1：查计算机类且价格 50 元以上图书的作者与出版社

题目：使用关系代数表达式写出类别名为“计算机类”、价格在 50 元以上的图书的作者与出版社。

涉及表：

- `tsb` 有作者、出版社、价格、类别ID。
- `tslbb` 有类别ID、类别名。

两表通过 `tsb.tslbid = tslbb.lbid` 连接。

答案：

```text
π zz, cbz ( σ lbm='计算机类' ∧ jg>50 ( tsb ⋈ tsb.tslbid=tslbb.lbid tslbb ) )
```

如果老师不要求写连接条件，也可简写为：

```text
π zz, cbz ( σ lbm='计算机类' ∧ jg>50 ( tsb ⋈ tslbb ) )
```

### 2.3 操作题2：查 2025-03-10 借出的逾期未还图书的读者 ID

题目字段都在借阅表 `jyb` 里，不需要连接。

答案：

```text
π dzid ( σ jyrq='2025-03-10' ∧ jyzt='逾期未还' ( jyb ) )
```

## 3. SQL 基础模板

### 3.1 建表模板

```sql
CREATE TABLE 表名 (
    字段1 数据类型 约束,
    字段2 数据类型 约束,
    PRIMARY KEY (字段1),
    FOREIGN KEY (字段2) REFERENCES 其他表(字段),
    CHECK (字段 IN ('值1', '值2'))
);
```

常用数据类型：

| 数据类型 | 用途 |
|---|---|
| `CHAR(n)` | 固定长度字符串，如编号 |
| `VARCHAR(n)` | 可变长度字符串，如姓名 |
| `DATE` | 日期 |
| `DECIMAL(8,2)` | 小数，适合价格 |
| `INT` | 整数 |

### 3.2 查询模板

```sql
SELECT 字段
FROM 表
WHERE 条件
GROUP BY 分组字段
HAVING 分组后的条件
ORDER BY 排序字段;
```

记住：

- 行过滤用 `WHERE`。
- 分组统计用 `GROUP BY`。
- 分组后的过滤用 `HAVING`。
- 多表查询用 `JOIN ... ON ...`。

## 4. 练习题1操作题逐题讲解

### 4.1 第3题：创建借阅表 `jyb`

题目要求：

- `jlid` 自动增加，增量为 1，主键。
- `dzid` 至少 8 位，外键，引用 `dzb(dzid)`。
- `tsid` 外键，引用 `tsb(tsid)`。
- `jyrq` 非空，默认当前日期。
- `jyzt` 检查约束，只能是“借出中”“已归还”“逾期未还”。
- 题干“如果图书未归还，则归还日期非空”疑似表述错误。按现实业务，未归还时归还日期应为空；已归还时归还日期应非空。

MySQL 写法：

```sql
CREATE TABLE jyb (
    jlid INT AUTO_INCREMENT PRIMARY KEY,
    dzid CHAR(8) NOT NULL,
    tsid INT NOT NULL,
    jyrq DATE NOT NULL DEFAULT (CURRENT_DATE),
    ghrq DATE NULL,
    jyzt VARCHAR(10) NOT NULL,
    CONSTRAINT fk_jyb_dzb FOREIGN KEY (dzid) REFERENCES dzb(dzid),
    CONSTRAINT fk_jyb_tsb FOREIGN KEY (tsid) REFERENCES tsb(tsid),
    CONSTRAINT ck_jyb_jyzt CHECK (jyzt IN ('借出中', '已归还', '逾期未还')),
    CONSTRAINT ck_jyb_ghrq CHECK (
        (jyzt IN ('借出中', '逾期未还') AND ghrq IS NULL)
        OR (jyzt = '已归还' AND ghrq IS NOT NULL)
    )
);
```

如果考试不要求写得这么严，可以简化：

```sql
CREATE TABLE jyb (
    jlid INT AUTO_INCREMENT PRIMARY KEY,
    dzid CHAR(8) NOT NULL,
    tsid INT NOT NULL,
    jyrq DATE NOT NULL DEFAULT (CURRENT_DATE),
    ghrq DATE,
    jyzt VARCHAR(10) CHECK (jyzt IN ('借出中', '已归还', '逾期未还')),
    FOREIGN KEY (dzid) REFERENCES dzb(dzid),
    FOREIGN KEY (tsid) REFERENCES tsb(tsid)
);
```

### 4.3 第5题：更新某读者 2025 年 3 月借阅的所有未还图书为今天归还

题目关键词：

- 读者 ID：`20231351`
- 2025 年 3 月借阅：`jyrq >= '2025-03-01' AND jyrq < '2025-04-01'`
- 未还：通常是 `ghrq IS NULL` 或 `jyzt <> '已归还'`
- 今天归还：`ghrq = CURRENT_DATE`
- 状态改为：`已归还`

答案：

```sql
UPDATE jyb
SET ghrq = CURRENT_DATE,
    jyzt = '已归还'
WHERE dzid = '20231351'
  AND jyrq >= '2025-03-01'
  AND jyrq < '2025-04-01'
  AND jyzt <> '已归还';
```

也可以写：

```sql
AND ghrq IS NULL
```

### 4.4 第6题：删除 2020 年 9 月之前注册的所有读者

```sql
DELETE FROM dzb
WHERE zcrq < '2020-09-01';
```

题目说这些读者所借图书已全部归还，所以不考虑外键冲突。若系统有外键且借阅记录仍存在，实际删除前可能要先处理 `jyb`。

### 4.5 第7题：统计某天注册读者未归还的哲学类图书数量

题目：统计注册日期为 `2021-09-01` 的读者，到目前为止尚未归还的“哲学类”类别图书数量。

思路：

1. 读者表 `dzb` 过滤注册日期。
2. 借阅表 `jyb` 判断未归还。
3. 图书表 `tsb` 找图书类别 ID。
4. 类别表 `tslbb` 找类别名“哲学类”。
5. 最后 `COUNT(*)`。

答案：

```sql
SELECT COUNT(*) AS 未归还哲学类图书数量
FROM dzb
JOIN jyb ON dzb.dzid = jyb.dzid
JOIN tsb ON jyb.tsid = tsb.tsid
JOIN tslbb ON tsb.tslbid = tslbb.lbid
WHERE dzb.zcrq = '2021-09-01'
  AND jyb.jyzt <> '已归还'
  AND tslbb.lbm = '哲学类';
```

如果老师习惯用归还日期判断未归还：

```sql
AND jyb.ghrq IS NULL
```

### 4.6 第8题：创建视图 `v_hep_cost`

题目：查询“高等教育出版社”出版的各个类别的图书总价。

“各个类别”说明要按类别分组。

答案：

```sql
CREATE VIEW v_hep_cost AS
SELECT tslbb.lbm,
       SUM(tsb.jg) AS 图书总价
FROM tsb
JOIN tslbb ON tsb.tslbid = tslbb.lbid
WHERE tsb.cbz = '高等教育出版社'
GROUP BY tslbb.lbm;
```

## 5. 应用题1：存储过程填空

题目代码：

```sql
DELIMITER $$
CREATE     ①       Proc(IN book_name VARCHAR(20) DEFAULT '%')
BEGIN
   SELECT jyb.sm, jyb.zz, jyb.dzid,         ②
   FROM            ③
   WHERE               ④           AND jyb.sm     ⑤     book_name;
END$$
DELIMITER ;
```

题目说按照书名模糊查询书名、作者、读者 ID、借阅日期。这里原题疑似把查询结果表也叫 `jyb`，但真实结构中 `jyb` 没有 `sm` 和 `zz`，所以应该连接 `jyb` 和 `tsb`。

推荐完整写法：

```sql
DELIMITER $$
CREATE PROCEDURE Proc(IN book_name VARCHAR(20))
BEGIN
   SELECT tsb.sm, tsb.zz, jyb.dzid, jyb.jyrq
   FROM jyb
   JOIN tsb ON jyb.tsid = tsb.tsid
   WHERE tsb.sm LIKE book_name;
END$$
DELIMITER ;
```

如果必须按填空原样使用 `jyb.sm`、`jyb.zz`，可能答案是：

| 空 | 答案 |
|---|---|
| ① | `PROCEDURE` |
| ② | `jyb.jyrq` |
| ③ | `jyb` 或一个已经包含图书信息的视图/表 |
| ④ | `1=1` |
| ⑤ | `LIKE` |

但更合理的规范答案应把 `FROM` 写成连接：

```sql
FROM jyb JOIN tsb ON jyb.tsid = tsb.tsid
WHERE tsb.sm LIKE book_name
```

注意：MySQL 的存储过程参数一般不支持 `DEFAULT '%'`，如果老师按教材伪代码给题，可以照填；实际 MySQL 可在调用时传入 `'%'`。

## 6. 应用题2：触发器填空

题意：归还图书时，如果超过应归还日期，借阅状态修改为“逾期未还”，系统自动把当前记录插入逾期表 `yqb`。逾期表结构与 `jyb` 相同。

题目代码：

```sql
DELIMITER $$
CREATE         ①           jyb_update
AFTER UPDATE ON               ②
FOR EACH ROW
BEGIN
   DECLARE record_num CHAR(6);
   SET        ③        = OLD.jlid;
   INSERT INTO         ④       SELECT * FROM jyb WHERE jlid =   ⑤    ;
END$$
DELIMITER ;
```

填空：

| 空 | 答案 |
|---|---|
| ① | `TRIGGER` |
| ② | `jyb` |
| ③ | `record_num` |
| ④ | `yqb` |
| ⑤ | `record_num` |

完整代码：

```sql
DELIMITER $$
CREATE TRIGGER jyb_update
AFTER UPDATE ON jyb
FOR EACH ROW
BEGIN
   DECLARE record_num CHAR(6);
   SET record_num = OLD.jlid;
   INSERT INTO yqb
   SELECT * FROM jyb WHERE jlid = record_num;
END$$
DELIMITER ;
```

更严谨的写法应该加条件，只有从非逾期变成“逾期未还”时才插入：

```sql
DELIMITER $$
CREATE TRIGGER jyb_update
AFTER UPDATE ON jyb
FOR EACH ROW
BEGIN
   IF NEW.jyzt = '逾期未还' AND OLD.jyzt <> '逾期未还' THEN
      INSERT INTO yqb
      SELECT * FROM jyb WHERE jlid = NEW.jlid;
   END IF;
END$$
DELIMITER ;
```

考试填空题一般按第一版填。

## 7. 应用题3：授权过程

题目：给王云授予图书表全部权限，还未创建登录名。

MySQL 写法：

```sql
CREATE USER '王云'@'localhost' IDENTIFIED BY '123456';
GRANT ALL PRIVILEGES ON 数据库名.tsb TO '王云'@'localhost';
```

如果用户名不能用中文，可写拼音：

```sql
CREATE USER 'wangyun'@'localhost' IDENTIFIED BY '123456';
GRANT ALL PRIVILEGES ON 数据库名.tsb TO 'wangyun'@'localhost';
FLUSH PRIVILEGES;
```

```sql
CREATE LOGIN wangyun WITH PASSWORD = '123456';

GRANT SELECT, INSERT, UPDATE, DELETE ON tsb TO wangyun;
```

若题目说“全部权限”，SQL Server 也可以写：

```sql
GRANT CONTROL ON tsb TO wangyun;
```

## 8. 应用题4：范式判断和分解到 3NF

### 8.1 题目信息

关系模式：

```text
tsjyb(tsid, sm, zz, cbz, cbrq, jg, tslbid, dzid, jyrq, ghrq, jyzt)
```

函数依赖：

```text
tsid -> sm, zz, cbz, cbrq, jg, tslbid
dzid, tsid -> jyrq, ghrq, jyzt
```

### 8.2 先求候选码

要确定整张表所有属性，至少需要：

- `tsid` 能推出图书信息。
- `dzid, tsid` 能推出借阅信息。

所以：

```text
(dzid, tsid)+ = {dzid, tsid, sm, zz, cbz, cbrq, jg, tslbid, jyrq, ghrq, jyzt}
```

因此候选码是：

```text
{dzid, tsid}
```

### 8.3 判断属于几范式

1NF：字段不可再分。这里默认满足 1NF。

2NF：在 1NF 基础上，非主属性不能部分依赖于候选码的一部分。

候选码是 `{dzid, tsid}`，但：

```text
tsid -> sm, zz, cbz, cbrq, jg, tslbid
```

也就是说，图书信息只依赖候选码的一部分 `tsid`，不依赖完整的 `{dzid, tsid}`。

所以存在部分函数依赖，不满足 2NF。

结论：

```text
该关系模式属于 1NF，不属于 2NF，也不属于 3NF。
```

### 8.4 分解到 3NF

按依赖拆表：

```text
图书表 TSB(tsid, sm, zz, cbz, cbrq, jg, tslbid)
借阅表 JYB(dzid, tsid, jyrq, ghrq, jyzt)
```

如果要更贴近原系统，还应有读者表和类别表：

```text
读者表 DZB(dzid, xm, dh, zcrq)
图书类别表 TSLBB(lbid, lbm)
图书表 TSB(tsid, sm, zz, cbz, cbrq, jg, tslbid)
借阅表 JYB(dzid, tsid, jyrq, ghrq, jyzt)
```

但仅根据题目给出的 `tsjyb` 依赖，核心分解写前两张即可。

## 9. 应用题5：求闭包 `(dzid, tsid)+`

闭包就是“从一组属性出发，能推出哪些属性”。

已知：

```text
F = {
  tsid -> sm, zz, cbz, cbrq, jg, tslbid,
  dzid tsid -> jyrq, ghrq, jyzt
}
```

求：

```text
(dzid, tsid)+
```

步骤：

```text
1. 初始闭包 X = {dzid, tsid}
2. 因为 X 中有 tsid，所以由 tsid -> sm, zz, cbz, cbrq, jg, tslbid，加入这些属性
   X = {dzid, tsid, sm, zz, cbz, cbrq, jg, tslbid}
3. 因为 X 中同时有 dzid 和 tsid，所以由 dzid tsid -> jyrq, ghrq, jyzt，加入这些属性
   X = {dzid, tsid, sm, zz, cbz, cbrq, jg, tslbid, jyrq, ghrq, jyzt}
4. 已经不能继续推出新属性，结束
```

答案：

```text
(dzid, tsid)+ = {dzid, tsid, sm, zz, cbz, cbrq, jg, tslbid, jyrq, ghrq, jyzt}
```

## 10. 应用题6：用 LRLRN 求候选码

LRLRN 是一种按属性在函数依赖左右出现情况分类的方法。常见分类：

| 类型 | 含义 | 作用 |
|---|---|---|
| L | 只在左边出现 | 一定在候选码中 |
| R | 只在右边出现 | 一般不在候选码中 |
| LR | 左右都出现 | 可能在候选码中 |
| N | 左右都不出现 | 一定在候选码中 |

题目依赖：

```text
tsid -> sm, zz, cbz, cbrq, jg, tslbid
dzid tsid -> jyrq, ghrq, jyzt
```

属性全集：

```text
U = {tsid, sm, zz, cbz, cbrq, jg, tslbid, dzid, jyrq, ghrq, jyzt}
```

分类：

- `dzid` 只在左边出现，所以是 L，必须在候选码中。
- `tsid` 只在左边出现，所以是 L，必须在候选码中。
- 其他属性只在右边出现，是 R，一般不进候选码。

所以候选码先取：

```text
X = {dzid, tsid}
```

求闭包：

```text
(dzid, tsid)+ = U
```

所以：

```text
候选码为 {dzid, tsid}
```

## 11. 理解题1：E-R 图怎么画

题目实体：

| 实体 | 属性 | 主键建议 |
|---|---|---|
| 学生 | 学号、姓名、性别、学院、注册日期 | 学号 |
| 课程 | 课号、课名、学分 | 课号 |
| 教师 | 工号、教师姓名、职称 | 工号 |
| 学习单元 | 单元id、标题 | 单元id |

联系：

| 联系 | 类型 | 联系属性 |
|---|---|---|
| 学生选修课程 | 多对多 M:N | 成绩 |
| 教师讲授课程 | 1:N | 教分 |
| 课程包含学习单元 | 1:N | 无 |

文字版 E-R 图可这样表达：

```text
学生(学号, 姓名, 性别, 学院, 注册日期)
  M ---- 选修(成绩) ---- N
课程(课号, 课名, 学分)

教师(工号, 教师姓名, 职称)
  1 ---- 授课(教分) ---- N
课程(课号, 课名, 学分)

课程(课号, 课名, 学分)
  1 ---- 包含 ---- N
学习单元(单元id, 标题)
```

如果试卷要求画图，矩形画实体，椭圆画属性，菱形画联系，连线标 `1`、`N`、`M`。

## 12. 理解题2：E-R 图转关系模式

转换规则：

1. 每个实体变成一张表。
2. 1:N 联系，把 1 方主键放到 N 方作为外键；联系属性也放到 N 方。
3. M:N 联系，单独建一张联系表，主键通常是两边主键组合。

关系模式：

```text
学生(学号, 姓名, 性别, 学院, 注册日期)
课程(课号, 课名, 学分, 工号, 教分)
教师(工号, 教师姓名, 职称)
学习单元(单元id, 标题, 课号)
选修(学号, 课号, 成绩)
```

主键标注：

```text
学生(_学号_, 姓名, 性别, 学院, 注册日期)
教师(_工号_, 教师姓名, 职称)
课程(_课号_, 课名, 学分, 工号, 教分)
学习单元(_单元id_, 标题, 课号)
选修(_学号_, _课号_, 成绩)
```

外键：

- `课程.工号` 引用 `教师.工号`。
- `学习单元.课号` 引用 `课程.课号`。
- `选修.学号` 引用 `学生.学号`。
- `选修.课号` 引用 `课程.课号`。

## 13. 理解题3：事务代码填空

题目是库存扣减，防止超卖。

原题空：

```sql
-- 开启事务
    ①     TRANSACTION;
-- 定义变量@current_stock
    ②      @current_stock INT;
--查询产品表 Products 中 101 商品数量 stock 并赋值给变量@current_stock
   ③      stock INTO @current_stock FROM Products WHERE id = 101;

IF @current_stock >= 1 THEN
    UPDATE Products SET stock = stock - 1 WHERE id = 101;
    -- 扣减成功
          ④      ;
ELSE
   -- 库存不足
          ⑤      ;
END IF;
```

MySQL 风格填法：

| 空 | 答案 |
|---|---|
| ① | `START` |
| ② | `DECLARE` |
| ③ | `SELECT` |
| ④ | `COMMIT` |
| ⑤ | `ROLLBACK` |

完整代码：

```sql
START TRANSACTION;
DECLARE current_stock INT;

SELECT stock INTO current_stock
FROM Products
WHERE id = 101
FOR UPDATE;

IF current_stock >= 1 THEN
    UPDATE Products SET stock = stock - 1 WHERE id = 101;
    COMMIT;
ELSE
    ROLLBACK;
END IF;
```

注意：`FOR UPDATE` 是加锁，防止两个事务同时读到同一个库存，考试如果没要求可以不写，但写上更严谨。

SQL Server 风格：

```sql
BEGIN TRANSACTION;
DECLARE @current_stock INT;

SELECT @current_stock = stock
FROM Products WITH (UPDLOCK)
WHERE id = 101;

IF @current_stock >= 1
BEGIN
    UPDATE Products SET stock = stock - 1 WHERE id = 101;
    COMMIT TRANSACTION;
END
ELSE
BEGIN
    ROLLBACK TRANSACTION;
END
```

### 14.12 范式判断模板

答题步骤固定写：

```text
1. 写出关系模式 R 和函数依赖 F。
2. 求候选码。
3. 判断是否满足 1NF：属性是否原子。
4. 判断是否满足 2NF：是否存在非主属性对候选码的部分依赖。
5. 判断是否满足 3NF：是否存在非主属性对候选码的传递依赖。
6. 给出结论。
```

常见结论：

```text
如果候选码是 AB，但 A -> C，则 C 部分依赖于 AB，所以不满足 2NF，只属于 1NF。
```

### 14.13 闭包模板

```text
求 X+：
1. X+ 初始等于 X。
2. 看函数依赖左边是否包含在 X+ 中。
3. 如果包含，就把右边加入 X+。
4. 重复直到不能加入新属性。
5. 如果 X+ 包含全部属性，则 X 是超码；若去掉任一属性后不再是超码，则 X 是候选码。
```

## 15. 考前最短复习路线

如果时间很少，建议这样背：

1. 先背关系代数三个符号：`σ` 是条件，`π` 是字段，`⋈` 是连接。
2. 背 SQL 增删改查：`INSERT`、`DELETE`、`UPDATE`、`SELECT JOIN GROUP BY HAVING`。
3. 背建表三件套：`PRIMARY KEY`、`FOREIGN KEY`、`CHECK`。
4. 背视图和索引：`CREATE VIEW`、`CREATE INDEX`。
5. 背授权：`CREATE USER`、`GRANT`。
6. 背范式判断：有部分依赖就不是 2NF，只能说 1NF。
7. 背闭包算法：从左边能推出右边，直到不变。
8. 背事务：成功 `COMMIT`，失败 `ROLLBACK`，并发库存要加锁。

## 16. 容易丢分的点

1. 日期不要写成中文日期，SQL 中写 `'2025-06-10'`。
2. 字符串必须加单引号。
3. 多表查询一定写连接条件，否则会笛卡尔积。
4. `WHERE` 不能用于聚合函数过滤，`SUM(...) > 20000` 要写在 `HAVING`。
5. `COUNT(*)` 是统计行数，`SUM(jg)` 是求总价。
6. 借阅未归还可以用 `jyzt <> '已归还'` 或 `ghrq IS NULL`，看题目字段描述。
7. MySQL 和 SQL Server 语法有差异，填空题要看题干格式：出现 `DELIMITER` 通常是 MySQL，出现 `@变量` 通常是 SQL Server。
