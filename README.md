## 📖 项目简介

本项目是内蒙古工业大学（IMUT）**软件工程专业**（SE）的学习资料合集，由学长学姐志愿整理和维护。

旨在解决一个普遍问题：课程资料零散、期末复习无从下手、选课时对各老师风格不了解。希望通过一届届的接力，让课程学习和资源获取变得更清晰、更公平，让信息壁垒不再成为学习路上的障碍。

> **适用人群**：内工大软件工程专业在校生（尤其适合低年级同学），也欢迎其他高校相关专业的同学参考。

## 📁 仓库结构

```text
📦 IMUT-SE-Resources
├── 📂 00-软工指南        # 入学须知、选课建议、老师评价、避坑指南
├── 📂 01-公共通识课      # 高数、英语、物理、思政等
├── 📂 02-学科基础课      # C语言、数据结构、计组、操作系统等
├── 📂 03-专业核心课      # 软件工程、数据库、网络、测试等
├── 📂 04-专业选修课      # 大数据、AI、移动开发等
├── 📂 05-实践教学        # 课程设计、实习实训（如青岛软件园）、毕设
├── 📂 06-考证与竞赛      # 软考、蓝桥杯、互联网+等
└── 📂 07-考研与就业      # 面经、简历模板、考研资料
```

> 📌 **当前进度**：仓库正在逐步建设中，欢迎同学们积极补充完善各模块内容。

## 🚀 快速开始

1.  **直接浏览**：点击上方目录进入对应文件夹即可查看。
2.  **下载文件**：若文件较多，可点击绿色的 `Code` 按钮 → `Download ZIP` 打包下载。
3.  **在线预览**：PDF、Markdown 文件可直接在 GitHub 上点击预览。

## ⚠️ 使用须知

1.  **严正声明**：本仓库所有资料仅用于**个人学习与参考**，严禁直接抄袭代码、作业或试卷内容用于提交。任何因抄袭导致的学术不端后果，仓库维护者概不负责。
2.  **版权归属**：课件、试卷等资源的版权归原作者（学院或老师）所有。若任何内容侵犯了您的权益，请通过 Issue 或邮件联系我们，我们会尽快处理。
3.  **资料时效**：课程大纲、考试形式和老师要求会随时间变化，请务必以当前学年实际情况为准，谨慎参考历史资料。

## 🤝 如何贡献

非常欢迎每一位受益于此仓库的同学加入维护，让这份资料薪火相传。

你可以通过以下方式贡献：

-   **提交资料**：Fork 本仓库 → 上传你的笔记、代码或心得 → 发起 Pull Request。
-   **反馈问题**：点击上方的 `Issues` 标签，报告错误链接、内容缺失或提出改进建议。
-   **成为维护者**：长期活跃的贡献者可以申请成为本仓库的 Collaborator。

详细的贡献指南请参考：[CONTRIBUTING.md](CONTRIBUTING.md)
